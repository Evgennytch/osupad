⦿osu! RP2040 Keypad & Configurator⦿
Официальный репозиторий прошивки и десктопного конфигуратора для 3-кнопочной клавиатуры (кейпада)
на базе микроконтроллера Waveshare RP2040-Zero.Проект превращает плату в USB-HID клавиатуру с 
частотой опроса до 1000 Гц, аппаратной поддержкой Eager Debounce (антидребезг с мгновенным откликом),
динамической настройкой RGB-подсветки и сохранением всех параметров во Flash (EEPROM).🔥
ОсобенностиАппаратный USB-HID + CDC: Устройство определяется как клавиатура и COM-порт одновременно.
 Настройка происходит на лету без перезагрузки платы.Высокая частота опроса: Выбор между 125, 250, 500, 750 и 1000 Гц.
 Настраиваемый Anti-Chatter (0–10 мс): Алгоритм мгновенного срабатывания на первом фронте (Eager Debounce) без задержки 
 ввода.ASCII Переназначение: Возможность назначить любую печатную ASCII-клавишу (буквы, цифры, знаки препинания) на 
 любую из 3 кнопок.RGB-подсветка: Полная настройка цвета встроенного адресованного светодиода NeoPixel (WS2812).
 Энергонезависимая память: Все параметры сохраняются во Flash-память RP2040 и применяются сразу при подаче питания.
 Удобный GUI (CustomTkinter):Автоматический поиск подключенного кейпада по Vendor ID (2E8A) или COM-порту.Сворачивание в 
 системный трей (pystray).Тёмная/светлая тема под стиль системы.🛠 Назначение выводов (Pinout)ЭлементПин
