# Windows configurator

Download and run `osupad.exe`. No Python installation is needed.

The board should run the firmware in this repository and appear as a USB CDC serial port. On first use, select **Автопоиск** or choose the board's COM port. The app verifies the connection with `PING/PONG` before reading or changing settings.

SHA-256 is recorded in `SHA256SUMS.txt` at the repository root.
